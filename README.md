# GENESIS — The God Engine

A living, deterministic synthetic biosphere driven by thermodynamics, spatial resource dynamics, heritable neural controllers, and causal timeline branching.

## Run locally

Open `index.html` in a modern browser, or serve the folder:

```bash
npx --yes serve .
```

Then click **Begin Genesis**.

- Deterministic seeded simulation (Mulberry32 PRNG)
